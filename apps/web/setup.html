樱花内网步骤

  1. 新建 HTTP/HTTPS 隧道。
  2. 目标填 127.0.0.1，端口填上面的 Gateway 端口。
  3. 确保支持 WebSocket Upgrade。
  4. 把分配的 HTTPS 地址填入“手机访问地址”（http:// 地址会被拒绝保存）。
  5. 手机打开地址，注册/登录后输入配对码。

虚拟局域网模式下，重启服务后用虚拟网卡 IP 加端口访问。樱花隧道走公网，明文 HTTP 会暴露账号密码和消息内容，因此 Gateway 强制要求 HTTPS 地址。
